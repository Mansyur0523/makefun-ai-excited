A colossal whale swims **up** through a sunset sky to touch the sun — a tiny hot-air balloon drifting beside it shows just how enormous it is.

`main.py` (Python 3.13, standard library only) draws the whole scene procedurally — gradient sunset sky, glowing sun, stars, clustered clouds, the whale with gold rim-light and pale belly, speed streaks, birds, the balloon, and a tiny lit city skyline at the bottom — and writes one deterministic 1024×1024 PNG to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`). Two runs produce byte-identical output.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
